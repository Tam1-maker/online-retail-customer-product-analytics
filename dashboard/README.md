# Dashboard

## Overview

This dashboard provides an interactive overview of customer and product performance using the Online Retail II dataset.

The dashboard focuses on identifying key revenue trends, customer purchasing behavior, and top-performing products to support data-driven business decisions.

## Key Analysis

The dashboard covers:

* Revenue and order performance
* Monthly revenue trends
* Customer purchasing behavior
* Top customers by revenue
* Customer segmentation
* Top-performing products
* Product sales performance

## Key Metrics

* Total Revenue
* Total Orders
* Total Customers
* Average Order Value
* Repeat Customer Rate

## Tools

* Power BI
* SQL
* Python
* Pandas
